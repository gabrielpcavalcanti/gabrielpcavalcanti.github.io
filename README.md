# Site de aulas · Gabriel Cavalcanti

Landing page em HTML, CSS e JS puro (sem dependências).

## Estrutura
- `index.html`: conteúdo
- `css/style.css`: estilos
- `js/main.js`: WhatsApp, menu mobile e animações

## Configurar
Edite o número em `js/main.js` (constante `WHATSAPP`).

## Rodar localmente
Abra o `index.html` no navegador.

## Publicar
1. Crie um repositório no GitHub e envie o código:
   `git init && git add . && git commit -m "primeira versão"`
   `git branch -M main && git remote add origin <URL> && git push -u origin main`
2. Conecte o repositório ao Cloudflare Pages, Netlify ou GitHub Pages (grátis).
3. Nas configurações do serviço, adicione seu domínio próprio e ajuste o DNS conforme indicado.
